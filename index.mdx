## Get started with API or MCP

New accounts receive **250 one-time signup credits** per account. Use credits with the API or MCP without a subscription. [Create an API key](https://www.tryfundable.ai/api-access/) or [connect Fundable MCP](/fundable-mcp).

**Check your balance or buy credits:** Visit the [Credits page](https://www.tryfundable.ai/credits). See [Pricing and Credits](/usage) for endpoint costs.

Pro is $100/month with 2,000 monthly credits, the web app, deal alerts, and integrations. That is $0.05 per included credit; additional purchased credits cost $0.06 each.

**Make Your First API Call**: Read our API documentation and view example recipes to understand how the API works. Check out some [example code](https://github.com/Jklionsky/fundable-api-example.git) on how to use the API.

## Data coverage

Fundable covers 101,000 startups, 375,000 startup employees, 67,000 investment firms, 36,000 angels, and 49,000 lead partners. Funding histories link to source articles, and data refreshes multiple times daily.


## Using Fundable with an AI assistant

Connect directly through the Fundable REST API or [Fundable MCP](/fundable-mcp), or
use a third-party catalog such as [Monid](https://monid.ai/), [Delegate
(DLGT)](https://dlgt.io/), [Orthogonal](https://www.orthogonal.com/),
[FluxaPay](https://agentmarket.fluxapay.xyz/marketplace/apis/fundable), or
[Superpowers](https://superpowers.tools/tools/fundable.funded-companies). For a
third-party connection, follow its listing for setup, authentication, billing, and
available tools. See [Endpoint Selection for AI Agents](/guides/agent-endpoint-selection)
to compare connection paths and choose Fundable endpoints.
